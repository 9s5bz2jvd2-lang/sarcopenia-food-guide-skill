# 肌少症食养助手

基于《成人肌少症食养指南（2026年版）》的AI对话科普助手

国家卫生健康委办公厅发布的官方指南，完整蒸馏为15个知识点（KPK），支持100轮深度对话咨询。

## 功能特点

- **风险评估**：SARC-F量表自评，握力/小腿围/步速切点查询
- **食养原则**：7条官方原则的详细解读与实操建议
- **蛋白质指导**：精确摄入量计算、三餐分配方案、食物等价交换
- **营养补充**：乳清蛋白/亮氨酸/CaHMB/维生素D的剂量与注意事项
- **地区食谱**：7大地区×4季节×3能量等级食谱概览
- **中医食养**：3种证型12个食养方的配方与辨证选用
- **合并疾病**：肥胖/糖尿病/肾病/肿瘤的个体化食养调整

## 快速开始

### 5步自评

1. 举起4.5kg物品有无困难？（0/1/2分）
2. 步行穿过房间有无困难？（0/1/2分）
3. 从椅子起身有无困难？（0/1/2分）
4. 爬10个台阶有无困难？（0/1/2分）
5. 过去1年跌倒几次？（0次=0，1-3次=1，≥4次=2）

**总分≥4分** → 存在肌少症风险，建议进一步评估

### 关键数据速查

| 项目 | 推荐量 |
|------|--------|
| 蛋白质（肌少症） | 1.2-1.5g/kg/天 |
| 每餐蛋白质 | 20-25g |
| 优质蛋白占比 | ≥60% |
| 乳清蛋白补充 | 20-40g/天 |
| 小腿围（男/女） | ≥34cm/≥33cm |
| 握力（男≥65岁） | ≥28.0kg |
| 握力（女≥65岁） | ≥18.0kg |
